# Game3D
Простая 3d стрелялка которую я буду обновлять.
Версия 1.1

## Примечание
Игра пока что работает только на Linux

## Сборка

Нужны компилятор C, make и библиотеки X11/OpenGL
(Debian/Ubuntu: `libx11-dev libgl1-mesa-dev libglu1-mesa-dev`).

```sh
make          # собрать ./game3d
make run TEXTURE=texture.raw MAP=map.txt
make asan     # сборка с AddressSanitizer/UBSan
make clean
```

Запуск: `./game3d <файл-текстуры.raw> [файл-карты.txt]` (формат текстуры в `image.h`).
Если аргумент карты опущен или файл не найден, используется процедурная генерация (fallback).

Формат карты:
Каждая строка описывает куб в виде:
```
x y z sx sy sz
```
Строки с `#` или пустые строки игнорируются.

Управление: **WASD** — движение (работает и в русской раскладке),
**мышь-обзор** — стрелки, **Shift** — бег, **Space** — прыжок, **Esc** — выход.

## Структура

```
main.c            цикл игры, ввод с клавиатуры -> PlayerInput
map/
    map.c/h       загрузка и отрисовка карты из файла, коллизии с кубами
    gen.c/h       процедурная генерация мира, чанки, высоты рельефа
image.c/h         .raw-файлы: чтение и форматы пикселей (RGB888/ARGB8888/RGB444/ARGB4444)

render/
    glx.c/h       окно, контекст OpenGL, ввод (единственное место с X11)
    render.c/h    кадр: камера, проекция, туман, отрисовка мира
    prim.c/h      текстуры и геометрия поверхностей: раскладка текстуры без
                  растяжения (см. «Текстуры»)

physics/
    physics.c/h   игрок: движение, гравитация, прыжок, поворот камеры
    coll.c/h      коллизии коллайдера-цилиндра с рельефом и объектами карты
```
