# Game3D
Простая 3d стрелялка которую я буду обновлять.

## Примечание
Игра пока что работает только на Linux

## Сборка

Нужны компилятор C, make и библиотеки X11/OpenGL
(Debian/Ubuntu: `libx11-dev libgl1-mesa-dev libglu1-mesa-dev`).

```sh
make          # собрать ./game3d
make run TEXTURE=texture.raw
make asan     # сборка с AddressSanitizer/UBSan
make clean
```

Запуск: `./game3d <файл-текстуры.raw>` (формат описан в `image.h`).

Управление: **WASD** — движение (работает и в русской раскладке),
**мышь-обзор** — стрелки, **Shift** — бег, **Space** — прыжок, **Esc** — выход.

## Структура

```
main.c            цикл игры, ввод с клавиатуры -> PlayerInput
gen.c / gen.h     процедурная генерация мира, чанки, высоты рельефа
image.h           формат .raw-текстуры

render/
    glx.c/h       окно, контекст OpenGL, ввод (единственное место с X11)
    render.c/h    кадр: камера, проекция, туман, отрисовка мира
    prim.c/h      текстура и геометрия одной клетки рельефа

physics/
    physics.c/h   игрок: движение, гравитация, прыжок, поворот камеры
    coll.c/h      коллизии коллайдера-цилиндра с рельефом
```

## Рельеф

Форма генерации настраивается константами в `gen.h` (всё «в клетках»,
одна клетка = `GEN_CELL_SIZE` = 0.25 м). По умолчанию — равнины с пологими
холмами, без гор и стен:

| параметр | что делает |
|---|---|
| `GEN_MAX_HEIGHT` | потолок рельефа: насколько высокими получаются холмы |
| `GEN_NOISE_SCALE` | длина волны шума — ширина холма; больше = крупнее и реже |
| `GEN_PLAINS_CUTOFF` | порог шума: всё, что ниже, — ровная равнина |
| `GEN_PLAINS_GAIN` | крутизна склонов над порогом |
| `GEN_RELIEF_FLOOR` | 0 — между холмами абсолютная равнина, 1 — холмы везде |
| `GEN_PLAIN_ROUGH` | амплитуда лёгкой раскачки равнины, чтобы она не была «столом» |
| `GEN_TERRACE_STEP` | 1 — гладкий рельеф; 3+ — плоские площадки со стенами, местами нужен прыжок |

Плавность держится на двух приёмах в `gen.c`: `terrain_shape()` (срез шума по
порогу + smoothstep, из-за чего холм вырастает из равнины без излома) и дробный
квант высоты (`GEN_HEIGHT_SUBDIV`) — с квантом в целую клетку любой пологий
склон рассыпается на ступени по 0.25 м.
